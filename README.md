# Sentinel Chat

Build a stunning, modern AI chat application with a gorgeous color palette, designed like a high-end consumer AI product.

1. Authentication & Admin Gate:

- A clean, beautiful Login/Signup screen upon opening the app.

- Admin access logic: If logging in with designated admin credentials, it grants full access to the chat interface. Any other sign-up shows a restricted access / pending approval screen.

2. Main Chat Interface:

- Standard, clean AI chat layout: User messages appear in sleek floating bubbles on the right; AI responses appear in elegant dark-violet/indigo cards with soft glowing borders on the left.

- Smooth scrolling message history window with beautiful typography and subtle transitions.

3. Input & Quick Action Bar:

- Bottom input bar with smooth rounded corners, a clean placeholder ("Message Sentinel..."), and a vibrant gradient send button.

- Row of pill-shaped quick action chips underneath for quick prompts.

4. Mobile Responsiveness:

- Fully optimized for mobile phone browsers, offering a seamless, app-like chatting experience on smartphones.
